# 来年度から変わること

:::lead
来年度から、休日の部活動は地域のクラブが受け持つ。平日の部活動は今のまま学校で続ける。
:::

:::::pairs 今 | 来年度から
:::subject 受け持つところ
休日も学校の部活動として先生が見ている
:::
:::response 受け持つところ
地域のクラブ(スポーツ協会・文化団体)が休日の活動を受け持つ
:::
:::subject 指導する人
顧問の先生が休日に月平均16時間指導している
:::
:::response 指導する人
クラブに登録した指導者が教える。希望する先生は報酬を受けて指導者に登録できる
:::
:::subject 練習の場所
学校の中
:::
:::response 練習の場所
13部のうち5部は学校の外(学校から1.2〜4.5km)
:::
:::subject 費用
クラブの会費は無い
:::
:::response 費用
会費は月1,500〜3,000円(部による)、保険は年800円。就学援助の家庭は会費を免除
:::
:::::

# 移り方の日程

:::lead
6月に運動部3つで試し、9月から休日の活動をすべてクラブに移す。指導者はあと17人を集める。
:::

```process
steps:
  - {title: 説明, detail: 4月 保護者と生徒}
  - {title: 試行, detail: 6月 運動部3つ}
  - {title: 移行, detail: 9月 休日の活動をすべて, emphasis: true}
  - {title: 平日の検討, detail: 翌4月 平日の一部も}
```

::::column 指導者の登録
```chart

  - name: 指導者
```

::::
::::column 試行で確かめること {role=main}
- 指導者は要る58人に対して41人。9月までに残りの17人を集める
- 試行に入らない部は、9月まで今の休日の部活動を続ける
- 6月の試行では、練習の場所までの移動と会費の集め方を確かめる
- 試行の結果は、9月の移行の前に保護者にお知らせする
- 平日の部活動を移すかどうかは、翌4月から改めて検討する
- 希望する先生は報酬を受けて指導者に登録でき、足りない分を埋める手立ての1つになる
