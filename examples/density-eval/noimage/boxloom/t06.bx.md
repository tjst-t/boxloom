# 曜日ごとの出社の実態

:::lead
席400に対し出社は平均58%で、最も多い火曜でも76%。毎日100席以上が空いている。
:::

```chart
compare: timeSeries
unit: "%"
categories: [月, 火, 水, 木, 金]
emphasis: [火]
series:
  - name: 出社率
    values: [64, 76, 71, 62, 41]
```

- 社員420人に席400。平均の出社は58%(約244人)で、曜日の差が大きい
- 最も多い**火曜で76%(約319人)**、最も少ない金曜で41%(約172人)。火曜でも約80席、金曜には約230席が使われていない
- 席の数は「全員分」ではなく**出社の最大**を基準に決められる。業界の調べでは、席の数を出社の最大の1.1倍にした会社で満足度が高い

:::source
社内の入館の記録(曜日別の平均)、業界の調べ(席の数と満足度)
:::

# 自由化の案

:::lead
席を300に減らし、集中の席40と打ち合わせの小部屋8つを足す。面積は変えない。
:::

| 項目 | 今 | 案 | 差 |
| --- | --- | --- | --- |
| 自由に座る席 | 400 | 300 | −100 |
| 集中の席(1人用) | 0 | 40 | +40 |
| 打ち合わせの小部屋 | 0 | 8 | +8 |
| 座れる場所の合計 | 400 | 340 | −60 |
| 床の面積 | 3フロア | 3フロア | 同じ |

- 火曜の最大(約319人)に対し、座れる場所は340。1.1倍(約351)には少し足りないため、試行で実際の混み方を確かめる
- 得るものは費用の削減ではなく、集中と打ち合わせの場所。席の空きを探す時間と満足度で効果を測る

# 2階での試行

:::lead
まず2階の140人で3か月試す。3つの心配は試行の中で確かめ、全フロアに広げるかを決める。
:::

:::::pairs 心配 | 試行で確かめること
:::subject 火曜に席が足りるか
試算では火曜に76% × 140人 = **106人**が出社し、2階の席100を超える。
:::
:::response
集中の席と小部屋に座れる分を含めて足りるかを、毎週の予約と入館の記録で数える。足りなければ部署ごとに出社の曜日を分ける。
:::
:::subject 紙の書類の置き場所
自分の机が無くなると、紙の書類を置く場所が無くなる。
:::
:::response
試行の前に各自の書類の量を調べ、共用の棚に移す分と捨てる分を分ける。
:::
:::subject 部署の会話が減る
同じ部署の人が離れて座り、相談の機会が減る。
:::
:::response
満足度の調べで会話の量を聞く。減っていれば部署ごとの区画を決める。
:::
:::::

| 物差し | 測り方 |
| --- | --- |
| 席の空きを探す時間 | 試行の前と後に聞き取り |
| 満足度 | 試行の前と終わりに調べ |
| 会議室の予約の取りやすさ | 予約のシステムの記録 |
