# 参加者の推移と参加しない理由

:::lead
去年の参加は168人で5年前の約半分、4分の3が60代以上。参加しない理由の1位は「日が合わない」。
:::

:::::columns
::::column 去年の参加者の年代
```chart

unit: "%"

  - name: 参加者の割合
    values: [54, 22, 15, 9]
```
::::
::::column 参加者の推移 {role=main}
- 世帯は1,240。去年の参加は**168人**で、世帯の9%にとどまる
- 5年前は310人。5年で**142人(46%)減った**
- 40〜50代は15%、30代以下は9%。本番で避難を助ける側になる世代が訓練を経験していない
::::
:::::

:::::columns
::::column 参加しない理由(複数回答)
```chart
compare: item
unit: "%"
categories: [日が合わない, 知らなかった, 内容が毎年同じ]
emphasis: [日が合わない]
series:
  - name: 回答の割合
    values: [46, 31, 24]
```
::::
::::column 理由ごとの打ち手 {role=main}
- **日が合わない**:日曜の午前1回では仕事や行事のある人が出られない → 時間帯を増やす
- **知らなかった**:回覧だけでは届かない世帯がある → 届け方を変える
- **内容が毎年同じ**:一度出た人が二度目に来ない → 体験の中身を変える
::::
:::::

# 本番までの段取りと要配慮の人

:::lead
6月に決め、8月に案内して9月に本番。あわせて、支え手の決まっていない要配慮の人47人を減らす。
:::

```process
steps:
  - {title: 6月 やり方の決定, detail: 役員会で案を決め、予算を組む}
  - {title: 8月 案内, detail: 回覧に加え、学校と各マンションを通じて全世帯に届ける}
  - {title: 9月第1日曜 本番, detail: 休日の回と、同じ週の平日の夜の回。会場は小学校の体育館(収容450人)}
  - {title: 9月下旬 振り返り, detail: 年代ごとの参加者を数え、次の年のやり方に生かす, emphasis: true}
```
