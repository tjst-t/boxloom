# 本体の価格

:::lead
本体は7,980円を推す。買いたい人が最も多く、1台の粗利と掛け合わせた見込みも3案で最も大きい。
:::

```chart
compare: item
unit: "%"
categories: [7980円, 9980円, 12800円]
emphasis: [7980円]
series:
  - name: 買いたい
    values: [34, 22, 9]
```

| 本体の価格 | 買いたい | 1台の粗利 | 割合 × 粗利 |
| --- | --- | --- | --- |
| 7,980円 | 34% | 4,880円 | 1,659 |
| 9,980円 | 22% | 6,880円 | 1,514 |
| 12,800円 | 9% | 9,700円 | 873 |
: 粗利は本体の原価3,100円を引いた額。右の列は100人あたりの粗利(千円)

- 競合3製品は6,480円・8,900円・13,200円。7,980円は中ほどの価格帯の最も手前に入る
- 買う人が多いほど、後で売れるカートリッジも増える

:::source
購入意向の調べ(回答1,500人、30〜60代)、店頭での競合の価格の調べ、原価は試作の見積り
:::

# カートリッジの継続

:::lead
利益の柱はカートリッジ。1個の粗利は1,560円で、本体を売った後も3か月ごとに入る。
:::

```chart
compare: timeSeries
unit: 千台
categories: [1年目, 2年目, 3年目]
series:
  - name: 本体
    values: [40, 65, 80]
```

- 価格は1,980円、原価は420円。**1個の粗利は1,560円**(79%)
- 3か月で替えるので、使い続ける人は年に4個を買う
- 1年後も使い続ける人は**55%**。1年目の40千台なら、2年目に約22千人が年4個を買う見込み
- 競合のカートリッジは1,650〜2,400円。1,980円は中ほどで、値下げの余地は小さい
- 継続の割合を上げる手(交換の時期の知らせ・定期の配送)を発売と同時に用意する

:::source
販売の計画(企画チーム、3年分)、継続の割合は社内の類似製品の実績、競合の価格は店頭の調べ
:::

# 発売までの日程と部品の懸念

:::lead
7月の発売を目指す。弁の取引先が1社で納期12週のため、量産の発注を3月の試作の前に出す。
:::
