- 大学の寮は120室で、**空き待ちが64人**。民間の部屋を借りようにも、37%は保証人がいない
- 去年の退学・休学は14人。理由の1位は**経済(6人)**で、住まいと仕事の不安が学業を続けられるかに直結する

# 3つの施策

:::lead
上位の困りごとに1つずつ施策を当てる。ただし3つ合わせると年1,270万円で、枠を270万円超える。
:::

| 施策 | 当たる困りごと | 中身 | 年の費用(万円) |
| --- | --- | --- | --- |
| 1 保証人の代わり | 住まい探し(48%) | 大学が保証人の代わりになる;家賃の滞りに備えて積み立てる;借りる部屋の家賃に上限を決める | 300 |
| 2 バディ | 孤立(27%)・アルバイト探し(31%) | 日本人学生の相棒を1人ずつ付ける;最初の学期は月1回以上会う;相棒に謝礼を払う | 450 |
| 3 手続きの付き添い | 日本語の手続き(44%)・病院(22%) | 窓口に職員を1名置く;役所・銀行・病院に付き添う;よく使う手続きの説明を英語でも配る | 520 |
| 合計 | | | 1,270 |
: 予算の枠は年1,000万円 {total=last points=中身}

- 施策1は寮の空き待ち64人の受け皿にもなる。保証人がいない37%が民間の部屋を借りられる
- 施策3は1名で380人を受けるため、手続きの多い4月と10月に予約が集中する見込み
- 施策2は孤立とアルバイト探しに効くが、効果を数で測りにくい。小さく始めて確かめる余地がある

:::takeaway
どれかを削るのではなく、施策2の規模を絞って枠に合わせる
:::
