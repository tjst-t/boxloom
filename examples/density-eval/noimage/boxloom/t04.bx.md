# 品目ごとの売上

:::lead
売上の半分は野菜だが、加工品は客1人あたりの単価が野菜の1.8倍あり、目に入る場所に置く価値がある。
:::

:::::columns
::::column 品目ごとの売上(年、万円)
```chart

```
::::
::::column 読み取り {role=main}
- 年の売上は合計6,490万円で、野菜が53%を占める
- 加工品は860万円で3番目だが、1人あたりの単価は1,450円(野菜は820円)
- 加工品の棚は今は奥にあり、野菜だけを買う客の目に入りにくい
- 入口に移せば、野菜を買いに来た客が加工品を手に取る機会が増える

# 3つの案と生産者の負担

:::lead
3つの案をまとめて来年度から始めることを提案する。朝の搬入が早くなる9戸の負担は、前日の夕方の搬入で軽くする。
:::

| 案 | 変えること | ねらい | 生産者の負担 |
| --- | --- | --- | --- |
| 案1 | 土日の開店を朝8時に(今は9時) | 葉物が売り切れる前の客を増やす | 朝の搬入が早くなる |
| 案2 | 平日の午後の品出しを減らし、夕方4時に閉店(今は5時) | 客の少ない時間の手間を減らす | 平日の残りが減る |
| 案3 | 加工品の棚を入口に移す | 単価の高い加工品を目に入れる | なし(配置を変えるだけ) |

:::::pairs 生産者の声 | 対応
:::subject
朝の搬入が早いのは負担(22戸中9戸)
:::
:::response
土日の葉物以外は前日の夕方の搬入を受け付け、朝に運ぶ量を減らす
:::
:::subject
平日の売れ残りの持ち帰りが手間
:::
:::response
午後の品出しを減らして売れ残りを少なくし、閉店の1時間前に値引きする
:::
:::subject
時間が変わることを客にどう知らせるか
:::
:::response
ポイントカードの会員1,860人に店頭とカードの案内で知らせ、月1回以上来る41%から広める
:::
:::::

- 見直しで見る数字:土日の葉物が売り切れる時刻、平日の夕方の残りの量、加工品の売上

:::takeaway
来年度は**案1・案2・案3**を4月から試し、半年後に客数と売り切れの時刻で見直す
:::
