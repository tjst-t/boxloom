:::lead
席は400あるが平均の出社は58%で、最も多い火曜でも76%にとどまる。
:::

# 席の再配置の案

:::lead
面積は変えずに席を300に減らし、集中の席と小部屋を足す。賃料は下がらず家具とシステムの費用がかかる。
:::

| 項目 | 今 | 案 |
| --- | --- | --- |
| 自由席 | 400 | 300 |
| 集中の席 | 0 | 40 |
| 打ち合わせの小部屋 | 0 | 8 |
| 面積 | 3フロア | 同じ |
: 席と部屋の数

| 費用 | 金額 |
| --- | --- |
| 家具(初回) | 2,300万円 |
| 予約のシステム | 年 360万円 |
| 賃料の削減 | なし(同じ面積) |
: 費用の見積もり

:::takeaway
狙いは費用の削減ではなく、**働く場所の種類を増やす**こと
:::

:::source
家具・システムは業者の見積もり
:::

# 2階での試行

:::lead
2階の140人で3か月試し、火曜の席の不足と書類・会話の心配を物差しで確かめる。
:::

:::::pairs 心配 | 試行で確かめること
:::subject 火曜に席が足りるか
試算では 76% × 140人 = 106人が出社し、2階の席100を6人上回る
:::
:::response
火曜の空席の数と、席を探す時間を毎週記録する
:::
:::subject 紙の書類の置き場所
自席が無くなり、書類を置いておけない
:::
:::response
個人のロッカーと部署の共用棚を用意し、使い勝手を聞く
:::
:::subject 部署の会話が減る
同じ部署の人が離れて座る
:::
:::response
満足度の調べで会話の量を聞き、会議室の予約の取りやすさも見る
:::
:::::
