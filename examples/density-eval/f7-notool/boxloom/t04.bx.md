# 客の来かたと売れかた

:::lead
客は土日に平日の約3倍来て、葉物は土日の午前に売り切れる。平日の午後3時以降の客は全体の12%しかいない。
:::

- 土日は1日 240〜260人、平日は 72〜110人。土日の午前 11時までに葉物の **6割** が売り切れる
- 平日の午後 3時以降の客は全体の 12%。残った品は生産者が持ち帰っていて手間になっている
- 加工品の客1人あたりの単価は 1,450円で、野菜(820円)の約1.8倍。売上はまだ小さく伸ばす余地がある

# 3つの案

:::lead
3つの案はどれも今の売れかたに合わせたもの。土日の早い開店は、生産者の朝の搬入の負担が課題になる。
:::

::::topics
:::topic 土日の朝 8時開店(今 9時) {label=1}
- 葉物が売り切れる前の土日の午前に、来られる客を増やす
- 生産者 22戸のうち 9戸が「朝の搬入が早いのは負担」と答えている
:::
:::topic 平日の夕方 4時閉店(今 5時) {label=2}
- 午後の品出しを減らし、午後 3時以降の 12%の客の分だけ売り場を縮める
- 残った品の持ち帰りの手間が減る
:::
:::topic 加工品の棚を入口に移す {label=3}
- 単価の高い加工品(1,450円)を最初に目に入るところに置く
- 配置を変えるだけで、生産者の負担は増えない
:::

# 来年度の進め方

:::lead
案2と案3は来年度の頭から始め、案1は搬入を分担できる生産者で土日の早い開店を試す。
:::

```phases
steps:
  - id: s1
    title: 4〜6月
    items:
      - {title: 加工品の棚を入口に移す, detail: 案3。配置だけを変える}
      - {title: 平日は夕方 4時閉店, detail: 案2。午後の品出しを減らす}
  - id: s2
    title: 7〜9月
    items:
      - {title: 土日 8時開店の試行, detail: 案1。朝の搬入を負担と答えた 9戸以外で分担, status: conditional}
      - {title: ポイントカードで来店を知らせる, detail: "会員 1,860人に早い開店を伝える"}
  - id: s3
    title: 10月〜
    items:
      - {title: 結果を見て決める, detail: 売り切れの時刻・売上・搬入の負担}
      - {title: 次の年の配置を決める, detail: 運営の会で決める}
legend:
  conditional: 生産者の合意が要る
```

- ポイントカードの会員 1,860人のうち、月1回以上来る人は 41%。案の知らせはまずこの人たちに届ける
