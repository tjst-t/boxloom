# 住民の利用の実態

:::lead
バスを週1回以上使う住民は23%にとどまる。一方で高齢化と免許の返納が進み、車のない人の足は欠かせない。
:::

::::stat
:::value 23 {unit=%}
バスを週1回以上使う住民
:::
:::value 29 → 38 {unit=%}
65歳以上の割合(10年前 → 今)
:::
:::value 140 {unit=件/年}
運転免許の返納
:::
::::

:::::columns
::::column 使わない理由(複数回答)
```chart
compare: item
unit: "%"
categories: [車がある, 便が少ない, 停留所が遠い]
emphasis: [便が少ない]
series:
  - name: 回答の割合
    values: [52, 41, 27]
```
::::
::::column 読み取り
- 一番多い理由は「車がある」52%で、車を持つ人はバスに戻りにくい
- 「便が少ない」41%・「停留所が遠い」27%は、便の組み方と停留所の置き方で応えられる
- 免許を返す人は毎年増えるため、路線をやめるなら代わりの足が要る
::::
:::::

:::takeaway
再編は、利用の少ない便を減らしつつ、車のない高齢者の**足を残す**形にする
:::

:::source
住民の調べ(回答 812人)、町の人口の統計、運転免許の返納の件数
:::

# 再編の案と日程

:::lead
東線は残し、西線は便を減らして病院に寄せ、山手線は予約の乗合の車に替える。10月から半年の試行で確かめる。
:::

| 路線 | 今 | 再編の案 |
| --- | --- | --- |
| 東線 | 1日 24便 | そのまま残す |
| 西線 | 1日 18便 | 1日 12便に減らし、病院に寄る |
| 山手線 | 1日 10便 | やめて予約の乗合の車(デマンド)に替える |
