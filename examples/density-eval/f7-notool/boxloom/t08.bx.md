# 本体の価格

:::lead
本体は7,980円を推す。買いたい人が最も多く、1人あたりの見込みの粗利も3案で最も大きい。
:::

| 本体の価格 | 買いたい割合 | 本体の粗利 | 割合 × 粗利 |
| --- | --- | --- | --- |
| 7,980円 | 34% | 4,880円 | 1,659円 |
| 9,980円 | 22% | 6,880円 | 1,514円 |
| 12,800円 | 9% | 9,700円 | 873円 |
: 粗利は本体の原価 3,100円を引いた額。「割合 × 粗利」は回答者1人あたりの見込み

::::::columns
:::::column 本体の価格ごとの買いたい割合
```chart

  - name: 買いたい割合

```
:::::
:::::column 競合とカートリッジ {role=main}
- 競合3製品の本体は 6,480円・8,900円・13,200円で、7,980円は下と中の間に入る
- カートリッジは 1,980円(原価 420円、粗利 1,560円)
- 競合のカートリッジは 1,650〜2,400円で、その中ほど
- 3か月ごとに替え、1年後も 55% が続ける見込み
:::::
::::::

:::note
買いたい割合は調べの上の意向で、実際に買う割合はこれより低くなる。3案の順位を比べるために使う
:::

:::source
購入の意向の調べ(回答1,500人、30〜60代)、競合の店頭の価格、社内の原価の見積もり
:::

# 販売の計画

:::lead
3年で本体を年8万台まで伸ばす。続けて買われるカートリッジが、本体の後の売上を支える。
:::

::::::columns
:::::column 本体の販売の計画(千台)
```chart
compare: timeSeries
unit: 千台
categories: [1年目, 2年目, 3年目]
emphasis: [3年目]
series:
  - name: 本体
    values: [40, 65, 80]
```
:::::
:::::column 読み取り {role=main}
- 3年で計 18.5万台
- カートリッジは3か月ごとに替える。1年後も55%が続ける見込み
- カートリッジ1個の粗利は 1,560円で、年4個なら 6,240円
- 続ける人の年の粗利は、本体1台の粗利(7,980円で 4,880円)を上回る
:::::
::::::

| 本体を 7,980円にしたとき | 1年目 | 2年目 | 3年目 |
| --- | --- | --- | --- |
| 販売(千台) | 40 | 65 | 80 |
| 本体の売上(億円) | 3.2 | 5.2 | 6.4 |
| 本体の粗利(億円) | 2.0 | 3.2 | 3.9 |
: 粗利は 1台 4,880円で計算。カートリッジの売上は含まない

:::source
販売の計画(商品企画部)、カートリッジの継続は購入の意向の調べからの見込み
:::

# 発売までの日程

:::lead
夏の需要に合わせて7月に発売する。弁の取引先が1社で納期12週のため、遅れれば9月になる。
:::
