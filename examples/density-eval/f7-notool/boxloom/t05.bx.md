# 移行で変わること

:::lead
来年度から、休日の部活動は地域のクラブが受け持ちます。対象は運動部9・文化部4の休日の活動です。
:::

::::stat
:::value 13 {unit=部}
対象の部(運動部 9、文化部 4)
:::
:::value 486 {unit=人}
生徒(部活動への加入 78%)
:::
:::value 41 / 58 {unit=人}
登録した指導者 / 要る指導者
:::
::::

| | 今 | 来年度から(休日) |
| --- | --- | --- |
| 受け持つところ | 学校(顧問の先生) | 地域のクラブ(スポーツ協会・文化団体) |
| 指導する人 | 顧問の先生(休日に月 平均 16時間) | クラブに登録した指導者(希望する先生も報酬ありで登録できる) |
| 練習の場所 | 学校 | 学校の外になる部が 5つ(1.2〜4.5km) |
| 費用 | なし | 会費 月 1,500〜3,000円と保険 年 800円(就学援助の家庭は会費を免除) |
| 相談の窓口 | 学校 | 学校の事務室とクラブの事務局(平日 9〜17時) |

- 平日の部活動は今のまま学校で続けます。平日の一部の移行は翌4月から検討します
- 先生の休日の部活動の時間は、月 平均 16時間から 0時間になります
- 指導者はあと 17人要るため、試行の間に登録を募ります

# 移行の日程

:::lead
6月に運動部3つで試し、9月から全部の休日の活動を移します。試行の様子は9月の前にお知らせします。
:::

```process
steps:
  - {title: 説明, detail: 4月。保護者・生徒への説明}
  - {title: 試行, detail: 6月。運動部 3つで先に始める}
  - {title: 全部の休日の活動, detail: 9月。13の部すべて}
  - {title: 平日の一部を検討, detail: 翌4月から}
```

```phases
steps:
  - id: p1
    title: 4〜5月
    items:
      - {title: 説明会と入会の受付, detail: 会費と免除の手続きの案内}
      - {title: 指導者の募集, detail: 希望する先生の登録も受け付ける}
  - id: p2
    title: 6〜8月
    items:
      - {title: 運動部 3つで試行, detail: 送り迎え・費用・指導の様子を確かめる}
      - {title: 試行の結果を報告, detail: 9月の前に保護者にお知らせ}
  - id: p3
    title: 9月〜
    items:
      - {title: 全部の休日の活動を移行, detail: 運動部 9・文化部 4}
      - {title: 平日の一部の検討, detail: 翌4月からの扱いを決める}
```

# ご不安への答え

:::
