# 本体の価格

:::lead
本体は7,980円を推す。買いたい人が一番多く、100人あたりの粗利も3つの案で一番大きい。
:::

::::columns
:::column 本体の価格ごとの「買いたい」

:::
:::column 価格ごとの粗利(本体)
| 本体の価格 | 1台の粗利 | 100人あたりの粗利 |
| --- | --- | --- |
| 7,980円 | 4,880円 | 16.6万円 |
| 9,980円 | 6,880円 | 15.1万円 |
| 12,800円 | 9,700円 | 8.7万円 |
: 本体の原価3,100円。100人あたり=買いたい割合×1台の粗利

- 9,980円は1台の粗利が大きいが、買う人が減る分で逆転する
- 台数が多いほど、後のカートリッジの売上も増える
:::

# 販売の計画

:::lead
3年で18.5万台を売る計画。利益の柱は本体よりカートリッジで、1年後の継続55%を守れるかが鍵になる。
:::

::::columns
:::column 販売の計画(年)

:::
:::column カートリッジの稼ぎ
| 項目 | 値 |
| --- | --- |
| 価格 | 1,980円 |
| 原価 | 420円 |
| 1個の粗利 | 1,560円 |
| 1人あたりの年の粗利 | 6,240円 |
: 3か月ごとに交換、年4個として

- 続けて使う1人の年の粗利は、本体1台の粗利(4,880円)より大きい
- 競合のカートリッジは1,650〜2,400円で、1,980円はその中ほど
- 1年後に続けて買う人は55%の見込み
:::

# 発売の時期

:::lead
夏の需要に合わせて7月に発売する。遅れの一番のもとは弁で、取引先が1社だけ・納期12週と余裕がない。
:::


- 弁は2社目の取引先を探すことを、発売の決定と合わせて進めたい
