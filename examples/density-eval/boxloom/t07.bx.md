# 今年の進め方

:::lead
今年は案1と案2を合わせて2回の訓練にし、費用は去年より18万円増える。案3は来年度に向けて検討する。
:::

::::stat
:::value +18 {unit=万円}
費用の増え(案1 6万円、案2 12万円)
:::
:::value 2 {unit=回}
訓練の回数(休日と平日の夜)
:::
:::value 450 {unit=人}
避難場所の体育館の収容
:::
::::

```process
steps:
  - {title: 6月 やり方の決定, detail: 本日の役員会で案1と案2を決める}
  - {title: 8月 案内, detail: 回覧に加えて子ども会を通じて知らせる}
  - {title: 9月第1日曜 本番, detail: 休日の回。子ども向けの企画を行う}
  - {title: 平日の夜の回, detail: 日は8月の案内までに決める}
```

- 2回に分けるので、参加が去年の倍になっても1回の人数は体育館に収まる
- 要配慮の人の名簿は登録86人、支援する人が決まっているのは39人。47人の支援する人の決め方は訓練とは別に話し合う
