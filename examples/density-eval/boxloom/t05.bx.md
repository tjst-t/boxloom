# 何が・いつ変わるか

:::lead
来年度、休日の部活動は地域のクラブに移る。6月に試し、9月に全部が移る。
:::

```process
steps:
  - {title: 説明, detail: 4月 保護者・生徒へ}
  - {title: 試行, detail: 6月 運動部3つ}
  - {title: 休日は全部移る, detail: 9月 13の部, emphasis: true}
  - {title: 平日の検討, detail: 翌4月 一部を検討}
```

| 休日の部活動 | 今 | 来年度の9月から |
| --- | --- | --- |
| 運営 | 学校 | 地域のクラブ(スポーツ協会・文化団体) |
| 指導する人 | 学校の先生 | クラブに登録した指導者(希望する先生も登録できる) |
| 練習の場所 | 学校 | 8つの部は学校、5つの部は学校の外 |
: 対象は休日の運動部 9・文化部 4。平日の部活動は来年度も学校で行う

- 生徒 486人のうち **78%**(約380人)が部に入っている。会費などの費用は4ページで説明する
- 先生の休日の部活の時間は月 平均 16時間 → 0時間になる

# ご心配へのお答え

:::lead
費用は月1,500〜3,000円で、就学援助の家庭は免除。送り迎えと指導者の数は、まだ課題が残る。
:::

:::::pairs ご心配 | 今決まっていること
:::subject
**費用**:会費はいくらかかるか。払えない家庭はどうなるか
:::
:::response
- 会費は **月 1,500〜3,000円**(部による)。ほかに保険が年 800円
- 就学援助を受けている家庭は **免除**
:::
:::subject
**送り迎え**:練習の場所が遠くならないか
:::
:::response
- 練習場所が学校の外になるのは **5つの部**。学校からの距離は 1.2〜4.5km
- ほかの 8つの部は、今と同じく学校で練習する
:::
:::subject
**指導の質**:指導する人は足りるか
:::
:::response
- 指導者の登録は今 **41人**、要るのは 58人で、**17人** 足りない
- 希望する先生は、クラブの指導者として登録できる(報酬あり)
:::
:::::

:::note
ご相談は学校の事務室とクラブの事務局で受ける(平日 9〜17時)
:::
