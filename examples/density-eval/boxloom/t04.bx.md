# 曜日と時間ごとの客

:::lead
客は土日に平日の約3倍来て、午前で葉物が売り切れる。平日の夕方の客は少ない。
:::

::::::columns
:::::column 1日の客数(平均)
```chart
compare: timeSeries
unit: 人
categories: [月, 火, 水, 木, 金, 土, 日]
emphasis: [土, 日]
series:
  - name: 1日の客数
    values: [85, 72, 78, 80, 110, 240, 260]
```
:::::
:::::column 読み取れること
- 土日は 240〜260人。平日(72〜110人)の約3倍
- 土日の **11時まで**に葉物の **6割** が売り切れる。昼前に来た客はもう葉物を選べない
- 平日の **午後3時以降** の客は全体の **12%**。残った品は生産者が持ち帰っている
:::::
::::::

:::takeaway
土日の朝は品が足りず、平日の夕方は品が余る。開ける時間を客の来る時間に寄せる
:::

# 売上と加工品

:::lead
加工品は単価が野菜の約1.8倍なのに、買われる回数は野菜の7分の1。野菜の客に加工品が届いていない。
:::

::::::columns
:::::column 年の売上(万円)
```chart
compare: item
unit: 万円
categories: [野菜, 果物, 加工品, 米, 花]
emphasis: [加工品]
series:
  - name: 年の売上
    values: [3420, 1180, 860, 620, 410]
```
:::::
:::::column 読み取れること
- 売上は合わせて **6,490万円**。野菜が半分を占める
- 加工品の客1人あたりの単価は **1,450円**、野菜は 820円
- 売上 ÷ 単価で見ると、年の買い上げは野菜 約 **4.2万回**、加工品 約 **0.6万回**。野菜を買う客の多くは加工品を買っていない
- ポイントカードの会員 1,860人のうち、月1回以上来るのは **41%**
:::::
::::::

:::takeaway
加工品を野菜の客の通り道に置けば、単価の高い品の売上を伸ばせる見込みがある
:::

# 3つの案と生産者の負担

:::lead
3つの案はどれも今の客の動きに合わせたもの。案1は朝の搬入の負担が増えるので、搬入の決め方と合わせて決めたい。
:::

| 案 | 変えること | 根拠 | 生産者の負担 |
| --- | --- | --- | --- |
| 1 土日の朝 | 開店を 9時 → **8時** | 土日の午前に葉物が売り切れる | 朝の搬入が早まる(今も 22戸中 9戸が負担と回答) |
| 2 平日の夕方 | 平日の午後の品出しを減らし、閉店を 5時 → **4時** | 午後3時以降の客は 12% | 残りの持ち帰りが減る |
| 3 加工品の棚 | 加工品の棚を入口に移す | 単価が野菜の約1.8倍 | 棚の入れ替えの作業が1回 |

この会で決めたいこと

1. 3つの案を来年度から行うか(案ごとに)
2. 案1を行うなら、8時に間に合わない戸の搬入をどうするか(前日の夕方の搬入を認めるか)
3. 試しに行う期間と、見直す時期
