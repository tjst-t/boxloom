# 3つの施策

:::lead
住まい・手続き・孤立の3つの困りごとに、それぞれ1つずつ施策を当てる。
:::

:::::pairs 困りごと | 施策
:::subject 住まい探し(48%)
- 大学の寮は空き待ちが64人
- 民間の部屋では37%に保証人がいない
:::
:::response 施策1 保証人の代わり
- 大学が保証人の代わりになる制度
- 年300万円を積み立てる
- 10月に見る数:寮の空き待ち、保証人がいない割合
:::
:::subject 日本語の手続き(44%)・病院(22%)
- 役所・銀行・病院の手続きが日本語で進む
- 窓口が日本語だけで、1人では進めにくい
:::
:::response 施策3 付き添いの窓口
- 職員1名を置き、手続きに付き添う
- 年520万円(人件費)
- 10月に見る数:手続き・病院で困る割合
:::
:::subject 孤立(27%)
- 相談できる日本人の知り合いがいない
:::
:::response 施策2 相棒(バディ)
- 日本人学生の相棒を1人ずつ付ける
- 謝礼は年450万円(予算の枠では180万円まで)
- 10月に見る数:孤立で困る割合
:::
:::::

:::source

# 予算と進め方

:::lead
3つを全部行うと1,270万円で、枠の1,000万円を270万円超える。施策1と3を全額、施策2を残りの180万円で絞って行う案を推す。
:::

| 組み合わせ | 費用 | 枠との差 | 届く困りごと |
| --- | --- | --- | --- |
| 3つとも全額 | 1,270万円 | 270万円超える | 全部 |
| **施策1・3を全額+施策2を絞る** | **1,000万円** | **0** | **全部(相棒は人数を絞る)** |
| 施策1・3だけ | 820万円 | 180万円残る | 住まい・手続き・病院 |
| 施策1・2だけ | 750万円 | 250万円残る | 住まい・孤立 |
: 年の費用。施策1 300万円、施策2 450万円、施策3 520万円
