# 席の使われ方

:::lead
平均の出社は58%で、400席のうち毎日ほぼ170席が空いている。一番多い火曜でも76%にとどまる。
:::

::::columns
:::column 曜日ごとの出社率
```chart

  - name: 出社率
    values: [64, 76, 71, 62, 41]
```
:::
:::column 読み取れること
- 社員420人に対し席は400。平均の出社58%なら使う席は約240
- 一番多い火曜でも約320人で、80席は空く
- 金曜は41%で、半分以上の席が空く
- 業界の調べでは、席の数を出社の最大の1.1倍にした会社の満足度が高い
:::

# 席の自由化の案

:::lead
面積はそのままで、固定の席を300に減らし、集中の席と打ち合わせの小部屋を足す。
:::

| 席の種類 | 今 | 案 | 使い方 |
| --- | --- | --- | --- |
| 固定の席 | 400 | 0 | 今は一人1席(社員420人) |
| 自由に座る席 | 0 | 300 | その日に空いている席を予約のシステムで選ぶ |
| 集中の席 | 0 | 40 | 一人で集中する作業 |
| 打ち合わせの小部屋 | 0 | 8 | 部署の短い打ち合わせ |
: 3フロアの合計。面積は同じ

::::stat
:::value 2,300 {unit=万円}
家具(初年だけ)
:::
:::value 360 {unit=万円/年}
予約のシステム
:::
:::value 0 {unit=万円}
賃料の削減(面積が同じため)
:::
::::

:::note
300席は火曜の出社(約320人)に集中の席40を合わせて足りる数
:::

# 試行の進め方

:::lead
まず2階だけで3か月、140人で試し、3つの物差しで続けるかを決める。
:::

::::stat
:::value 140 {unit=人}
試行の対象(2階)
:::
:::value 100 {unit=席}
2階の席の数
:::
:::value 3 {unit=か月}
試行の期間
:::
::::

:::::pairs 心配なこと | 試行で確かめること
:::subject 火曜に席が足りるか
試算では76% × 140 = 106人に対し、2階の席は100
:::
:::response 予約の記録
火曜の不足の日数と、集中の席・小部屋で吸収できるかを数える
:::
:::subject 紙の書類の置き場所
固定の席が無くなり、机に置けなくなる
:::
:::response 個人の棚
試行の前に書類の量を調べ、棚の数を決める
:::
:::subject 部署の会話が減る
同じ部署の人が離れて座る
:::
:::response 聞き取り
部署ごとに月1回、困りごとを聞く
:::
:::::

- 評価の物差し:席の空きを探す時間、満足度、会議室の予約の取りやすさ
- 今日決めたいこと:2階での3か月の試行と、家具と予約のシステムの手配
