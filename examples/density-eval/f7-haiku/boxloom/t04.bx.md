# 客は土日に集まり、午前に売り切れる

:::lead
土日の客は1日平均250人と平日の約3倍。土日の午前11時には葉物の6割が売り切れる。
:::

- 平日の午後3時以降の客は全体の12%
- 22戸のうち9戸が、朝の搬入が早いのを負担に感じている

# 3つの案で時間と売り場を見直す

:::lead
売り切れは朝、客が少ないのは平日の夕方なので、案1と案2で時間を、案3で売り場を動かす。
:::

| 案 | 変える点 | 材料の数字 |
| --- | --- | --- |
| 案1 土日の朝の開店 | 9時から8時へ | 土日の午前11時までに葉物の6割が売り切れる |
| 案2 平日の夕方の閉店 | 5時から4時へ | 平日の午後3時以降の客は全体の12% |
| 案3 加工品の棚の移動 | 入口に移す | 加工品の客単価は1,450円(野菜は820円) |
: 案1の朝の搬入の負担を生産者と話し合う

- 案2は平日の午後の品出しを減らすことになる
- 売り切れは土日の午前11時までに葉物の6割で、案1の開店時刻と重なる
- 案1は朝の搬入の負担と重なるため、生産者の声を聞いてから決める
- 平日の午後3時以降の客は全体の12%で、閉店を1時間早めても客の多くは残る
- 土日の朝8時から9時の客数は材料にないため、試行で確かめる
- 加工品の客1人あたりの単価は1,450円で、野菜の820円の約1.8倍
- 案1と案2は、生産者の朝の搬入と平日の残りの持ち帰りの手間にも関わる

# 売上の半分余りは野菜が占める

:::lead
売上6,490万円のうち野菜が3,420万円。売り切れが多いのは野菜なので、野菜の売り場が要になる。
:::

| 品目 | 年の売上(万円) |
| --- | --- |
| 野菜 | 3,420 |
| 果物 | 1,180 |
| 米 | 620 |
| 加工品 | 860 |
| 花 | 410 |
: 年の売上の合計 6,490万円

- ポイントカードの会員は1,860人、うち月1回以上来る人は41%(約760人)
- 持ち帰りの手間が平日の残りの野菜の負担になっている
- 果物の売上 1,180万円は野菜の約3分の1

:::takeaway
土日の朝に野菜を厚くするか、平日の夕方を縮めるかで、野菜の売り場の使い方が決まる
:::
