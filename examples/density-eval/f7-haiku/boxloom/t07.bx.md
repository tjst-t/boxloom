# 参加しない理由は日程と周知

:::lead
参加しない人の46%は「日が合わない」と答えた。平日の夜と休日の2回にする案1は、この理由に直接答える案。
:::

| 理由 | 割合 |
| --- | --- |
| 日が合わない | 46% |
| 知らなかった | 31% |
| 内容が毎年同じ | 24% |
: 参加しない理由(回覧の調べ、回答214人)

| 案 | 中身 | 費用 |
| --- | --- | --- |
| 案1 | 平日の夜と休日の2回にする | +6万円 |
| 案2 | 子ども向けの企画(消火器の体験・非常食の試食) | +12万円 |
| 案3 | マンションごとの小さな訓練を年3回 | 1回2万円 |
: 3つの案

- 「知らなかった」が31%あり、日程と周知の両方を見直す必要がある
- 「内容が毎年同じ」は24%。案2は内容を変える案
- 案1と案2を両方行うと、費用は+18万円
- 案3を年3回行うと、費用は6万円(1回2万円)

:::source
回覧の調べ(回答214人)、費用は案の見積もり(架空の資料)
:::

# 6月に決め、9月に本番

:::lead
6月に今年のやり方を決め、8月に案内を出して、9月第1日曜に本番を行う。
:::

| 時期 | 内容 |
| --- | --- |
| 6月 | やり方の決定 |
| 8月 | 案内 |
| 9月第1日曜 | 本番 |
: 日程の案

| 項目 | 数 |
| --- | --- |
| 避難場所(小学校の体育館)の収容 | 450人 |
| 要配慮の人の名簿の登録 | 86人 |
| 支援する人が決まっている人 | 39人 |
: 避難と要配慮の人

- 費用は案1の+6万円から、案2の+12万円まで
- 支援する人が決まっていない人の分は、本番までに決める必要がある
- 案内は8月に配る。案内の文面は6月の決定のあとに作る

:::note
日程は案で、6月の決定の会議で変わることがある
:::
