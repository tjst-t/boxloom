# 休日の部活動は地域のクラブに移る

:::lead
9月からは全部の休日の活動を地域のクラブが行い、先生の休日の部活の時間は月0時間になる予定。
:::

| 項目 | 数 |
| --- | --- |
| 休日の部活動(運動部) | 9 |
| 休日の部活動(文化部) | 4 |
| 生徒 | 486人 |
| 加入している生徒 | 78%(約380人) |
| 登録している指導者 | 41人 |
| 必要な指導者 | 58人 |
: 指導者は17人足りない

- 練習場所を移す部は、学校の外になる5つの部
- 先生の休日の部活の時間は、今は月平均16時間
- 移り先は、スポーツ協会と文化団体のクラブ
- 先生の休日の部活の時間は0時間になるが、希望する先生は指導者として登録でき、報酬がある

# 費用と送り迎えが不安の中心

:::lead
保護者の不安は費用と送り迎えに集まる。説明会では、この2つにどう答えるかが中心になる。
:::

```chart
compare: item
unit: " %"
categories: [費用, 送り迎え, 指導の質]
series:
  - name: 保護者が挙げた不安(複数回答)
    values: [52, 47, 35]
```

- 会費は月 1,500〜3,000円(部による)、就学援助の家庭は免除
- 保険は年 800円
- 練習場所が学校の外になる部は5つ、距離は 1.2〜4.5km
- 送り迎えは、距離 1.2〜4.5km の移動が必要になる
- 指導の質に不安があるのは35%
- 希望する先生は指導者として登録でき、報酬がある

# 日程と相談の窓口

:::lead
4月に説明し、6月に試行、9月に全部の休日の活動へ移る。相談は平日9〜17時に受け付ける。
:::

```process
steps:
  - title: 説明
    detail: 4月
  - title: 試行
    detail: 6月、運動部3つ
  - title: 全部の休日の活動
    detail: 9月
  - title: 平日の一部も検討
    detail: 翌年4月
```

- 相談の窓口は、学校の事務室とクラブの事務局
- 保護者の調べ(回答302人)では、賛成が44%、どちらともいえないが38%、反対が18%
- 6月の試行は運動部3つで行う
- 翌年4月に検討するのは、平日の一部も移すかどうか

:::takeaway
費用と送り迎えへの答えを、説明会で具体的に示すことが9月の移行の前提になる
:::
