# 西線と山手線の赤字が大半を占める

:::lead
3路線の赤字 6,750万円のうち69%は西線と山手線が占めるので、再編はこの2路線から考える。
:::

```chart
compare: item
unit: " 万円"
categories: [東線, 西線, 山手線]
series:
  - name: 年の赤字
    values: [2100, 2900, 1750]
```

- 1便あたりの乗客は、東線 6.1人、西線 3.2人、山手線 1.4人
- 町の補助は3路線の合計で年 6,750万円
- 西線の赤字 2,900万円は3路線で最も大きい
- 山手線は1日10便で、1便あたり1.4人と3路線で最も少ない

# 東線は残し、西線と山手線は替える

:::lead
東線は残し、西線は便を減らして病院に寄せ、山手線はデマンドの車に替える案。
:::

| 路線 | 案 | 数字 |
| --- | --- | --- |
| 東線 | 残す | 1日 24便 |
| 西線 | 便を12に減らし病院に寄る | 1日 18便から 12便へ |
| 山手線 | やめて予約の乗合の車(デマンド)にする | 1日 30回の予約、年 1,100万円、待ち 平均25分 |
: デマンドの費用は年 1,100万円

- 山手線の通学の8人は、デマンドでの扱いを決める必要がある
- デマンドの予約は電話だけでよいかを決める必要がある
- デマンドの費用は年 1,100万円で、山手線の赤字 1,750万円より少ない
- 1日10便・1便1.4人の山手線を、1日30回の予約で置き換える案
- 西線は1日の便が18便から12便になり、6便減る
- 東線は1便あたり6.1人で、3路線の中で最も乗られている
- デマンドの予約の仕組みを先に決めてから試行に入る

# 住民はバスを使わない理由に車を挙げる

:::lead
住民の半数が車があるから使わず、4割は便が少ないと答えている。回答は812人。
:::

```chart
compare: item
unit: " %"
categories: [車がある, 便が少ない, 停留所が遠い]
series:
  - name: バスを使わない理由(複数回答)
    values: [52, 41, 27]
```

- バスを週1回以上使う人は23%
- 65歳以上は38%で、10年前の29%から9ポイント増えた
- 運転免許の返納は年140件
- 説明会は5月、試行は10月から翌年3月まで、本格の実施は翌年4月

:::takeaway
「便が少ない」41%と「停留所が遠い」27%は、便数と停留所の位置の見直しで答えられる項目
:::
