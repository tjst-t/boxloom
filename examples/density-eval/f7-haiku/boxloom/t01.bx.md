# 夜の利用は駅前館に集まる

:::lead
平日の夜に人が集中するのは駅前館なので、延長はまず駅前館から始めるのが合理的。
:::

```chart
compare: timeSeries
unit: " 人/時"
categories: [9時台, 12時台, 17時台]
emphasis: [17時台]
series:
  - name: 駅前館・平日の利用
    values: [18, 41, 63]
```

- 17時台の利用は9時台の3.5倍で、閉館の前に集中している
- 閉館の前の30分に入れなかった人が、週に平均140人いる
- 年の利用者は中央館 412千人、駅前館 268千人

# 費用は案Bが案Aの約3倍で、見込みは1.6倍

:::lead
費用の少なさでは案Aが最も良く、案Bは費用が案Aの約3倍なのに見込みは1.6倍にとどまる。
:::

| 案 | 年の費用(万円) | 年の見込み | 夜の司書 |
| --- | --- | --- | --- |
| 案A 駅前館だけ平日21時まで | 1,800 | +38千人 | 2名増 |
| 案B 全館 平日20時まで | 5,200 | +61千人 | 7名増 |
| 案C 駅前館に24時間の受け取りの棚 | 900(初年)・150(以降) | +45千件(受け取り) | 記載なし |
: 案Cの見込みは本の受け取りの件数

- 案Cは閉館の後も使える受け取りの棚なので、開館時間とは別の利用を増やす
- 案Aの見込みは案Bの約6割で、費用は案Bの約35%
- 案Bは夜の時間の司書を7名増やす必要があり、案Aの2名より多い
- 案Aの司書の増員は2名で、案Bの7名の約3割

案Bは見込みが大きいが、費用と人手の増え方も大きい。まず案Aで試し、結果を見て広げるかを決める案として考えてほしい。

# 進め方と心配な点

:::lead
4月に試行を決めれば、9月から試行を始め、翌年3月に評価できる。心配は3つある。
:::

```process
steps:
  - title: 試行の決定
    detail: 4月
  - title: 職員の募集
    detail: 6月
  - title: 試行の開始
    detail: 9月
  - title: 評価
    detail: 翌年3月
```

心配な点は次の3つ。

- 北館の周りは夜の人通りが少ない
- 光熱費が年 6% 増える見込み
- 夜の時間の司書は、会計年度任用職員として研修が必要
- 試行の評価は翌年3月に行い、その結果を見て次の年度の開館時間を決める

:::takeaway
案Cの棚は以降の費用が年150万円で、案Aの年1,800万円の約8%
:::
