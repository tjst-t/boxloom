# 3つの施策と費用

:::lead
3つの施策を全部行うと年1,270万円になり、予算の枠1,000万円を270万円超える。
:::

| 施策 | 中身 | 年の費用(万円) |
| --- | --- | --- |
| 1 保証人の代わりの制度 | 大学が保証人の代わりになる | 300 |
| 2 日本人学生の相棒(バディ) | 1人ずつ、謝礼 | 450 |
| 3 手続きの付き添いの窓口 | 職員1名 | 520 |
| 合計 | 予算の枠は年1,000万円 | 1,270 |
: 施策と年の費用 {total=last}

| 予算 | 万円 |
| --- | --- |
| 予算の枠(年) | 1,000 |
| 3つの施策の合計 | 1,270 |
| 枠を超える分 | 270 |
: 予算と施策の合計

- 寮は120室に対して空き待ちが64人いる。寮だけでは足りない
- 施策は2つまでなら予算の枠に入る(最も高い2つは 450 + 520 = 970万円)
- 3つのうちどれを先にするかを決める必要がある

:::source
施策の費用の見積もり、寮の室数と空き待ち(架空の資料)
:::
