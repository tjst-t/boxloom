- 平均の出社(58% × 420人 = 約244人)に対しては、300席は今より100席少ないだけ
- 初年の費用は家具と予約のシステム(2,300万円 + 360万円 = 2,660万円)
- 紙の書類を置く場所は、席の数と一緒に決める

# 2階の試行で火曜の席と書類を確かめる

:::lead
2階だけ3か月試し、火曜の席の足りなさ・紙の書類の置き場所・部署の会話を見てから、全館に広げるか決める。
:::

| 試行で見る数 | 値 |
| --- | --- |
| 対象 | 2階の社員140人 |
| 期間 | 3か月 |
| 火曜の出社の見込み | 約106人(2階の席は100) |
| 全館の火曜の出社の最大 | 約319人(76% × 420人) |
: 試行の数

::::columns
:::column 心配なこと
- 火曜に席が足りるか
- 紙の書類の置き場所
- 部署の会話が減る
:::
:::column 評価の物差し
- 席の空きを探す時間
- 満足度
- 会議室の予約の取りやすさ
:::
::::

- 業界の調べでは、席を出社の最大の1.1倍にした会社の満足度が高い。案の300席は、最大の出社(約319人)より少ない
- 試行の間は、火曜に席が足りなかった日と時間を記録し、全館に広げるかの判断に使う
- 試行の結果は、今と同じ3つの物差し(席を探す時間・満足度・予約の取りやすさ)で比べる
- 足りなければ、3か月の後に席の数を見直してから全館の判断にする
