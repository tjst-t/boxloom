# 問い合わせの4割は、最初の窓口では片づかずに回されている

::::stat
:::value 41 {unit=%}
最初の窓口から別の窓口へ回された問い合わせの割合
:::
:::value 2.6 {unit=日}
回された問い合わせが片づくまでの平均の日数(回されないものは 0.8 日)
:::
:::value 7
利用者から見た窓口の数(電話 3・メール 2・フォーム 2)
:::
::::

- 回された問い合わせの多くは、利用者が窓口の分け方を知らないことが原因
- 窓口を1つにして受け付けたあとで振り分ければ、利用者は待たずに済む
- 振り分けの規則は、いまの7つの窓口の担当表からそのまま作れる

:::takeaway
窓口を1つにまとめ、振り分けは受け付けたあとに窓口の側で行う
:::

:::source
問い合わせの記録 12,480 件(2026 年 4〜9 月)の集計
:::

# 窓口をまとめる費用は、1年目の人件費の減りで回収できる

| 費目 | 1年目(万円) | 2年目(万円) |
| --- | --- | --- |
| 受付の仕組みの導入 | 1,200 | 0 |
| 振り分けの規則づくり | 300 | 100 |
| 担当の研修 | 150 | 50 |
| 窓口の人件費の減り | −1,800 | −1,800 |
| 差し引き | −150 | −1,650 |
: 費用は見積もり、人件費の減りは窓口の数と件数からの試算 {total=last}

- 1年目の導入費は、窓口を7つから1つにしたときの人件費の減りで賄える
- 2年目からは毎年 1,600 万円ほどの減りが続く(規則の手直しの費用を引いたあと)

:::takeaway
費用の面では、まとめない理由は無い。決めるべきは移る時期だけ
:::

:::source
導入費は3社の見積もり(2026 年 10 月)の中央の値。人件費は 2026 年度の窓口の配置から試算
:::

# 窓口をまとめるのは、来年4月の組織の見直しに合わせる {type=statement}

:::source

:::
