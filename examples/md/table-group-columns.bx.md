# 国・県・市の支援は、支援事業ごとに制度が分かれる

| 区分 | 支援事業 | 制度 | 対象 | 上限 |
| --- | --- | --- | --- | --- |
| 国 | 創業の支援 | 創業の補助 | 創業5年までの事業者 | 200 万円 |
| | | 専門家の派遣 | 創業5年までの事業者 | 年 10 回 |
| | 設備の支援 | 設備の補助 | 中小の事業者 | 1,000 万円 |
| 県 | 設備の支援 | 設備の貸付 | 県内の事業者 | 3,000 万円 |
| | | 利子の補給 | 県内の事業者 | 年 1% |
: 制度の一覧(2026 年度の案) {groups=区分,支援事業}

- 設備の支援は国と県の両方にあり、国は補助、県は貸付と利子の補給で分ける
- 創業の支援は国だけで、補助と専門家の派遣を組み合わせる
- 区分の境では、支援事業の名前が同じでも別の群として結合しない

# 国・県・市の支援は、支援事業ごとに制度が分かれる(続き)

| --- | --- | --- | --- | --- |
| 市 | 販路の支援 | 展示会の出展 | 市内の事業者 | 50 万円 |
| | | 通販の立ち上げ | 市内の事業者 | 30 万円 |
| | 人材の支援 | 採用の説明会 | 市内の事業者 | 無料 |
: {continues}

- 市の支援は販路と人材の2つで、どちらも上限の額が小さい
- 展示会の出展と通販の立ち上げは、同じ年度に両方は使えない

# 相談の窓口は、支援事業ごとに1つにまとめる

| 時期 | 支援事業 | 窓口 | 受付 |
| --- | --- | --- | --- |
| 4 月 | 創業の支援 | 創業の係 | 平日 |
| 5 月 | | 創業の係 | 平日と土曜 |
| 6 月 | 設備の支援 | 設備の係 | 平日 |
| 7 月 | | 設備の係 | 平日 |
: 2列目だけを群の列にする {groups=支援事業}

- 窓口は支援事業ごとに1つにし、月ごとに受付の曜日だけを変える
- 5 月は創業の相談が多いので、土曜も受け付ける
