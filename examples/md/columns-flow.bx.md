# 町の図書館の夜間返却

:::lead
返却の集まる時間を調べ、箱と当番の組み方を変えることにした
:::

:::::columns {flow=true}
:::column 分かったこと
- 返却の半分は閉館後の 20 時から 23 時に集まる
- 雨の日は箱の口から本が濡れる
- 箱が満ちると、入りきらない本が箱の上に置かれる
:::
:::column 打ち手
- 返却箱を2つに増やし、口に庇を付ける
- 箱が満ちたら翌朝の当番に知らせる
- 濡れた本は乾かしてから棚に戻す
:::
:::::

# 三つの段で進める

:::::columns {flow=true}
:::column 背景
利用者の聞き取りでは、夜間の返却を不便と答えた人が多かった
:::
:::column 試み
一つの分館で、返却箱を増やして三か月ためす
:::
:::column ゴール
すべての分館で、夜間の返却の待ちをなくす
:::
:::::

# 並べて読む二つの館

:::::columns
:::column 東の分館
- 夜間の返却は一晩に 40 冊ほど
- 箱は入口の右にある
:::
:::column 西の分館
- 夜間の返却は一晩に 15 冊ほど
- 箱は駐車場の側にある
:::
:::::
