# 図書館の夜間返却を見直す

:::lead
利用者への聞き取りで分かったことごとに、次の打ち手を1つずつ決めた
:::

:::::pairs 分かったこと | 打ち手
:::subject
返却の半分は閉館後の 20 時から 23 時に集まる
:::
:::response
- 返却箱を2つに増やす
- 箱が満ちたら翌朝の当番に知らせる
:::
:::subject
雨の日は箱の口から本が濡れる
:::
:::response
口に庇を付け、濡れた本は乾かしてから棚に戻す
:::
::::subject
:::quote 利用者 B、聞き取りにて
返したのに延滞の知らせが来て驚いた
:::
::::
:::response
- 箱の中身は開館と同時に読み取る
- 前の晩の返却日で記録する
:::
:::subject
返却箱の場所が入口から見えにくい
:::
:::response
入口の案内板に返却箱の矢印を足す
:::
:::::

:::source
架空の聞き取り(利用者 12 人)
:::
