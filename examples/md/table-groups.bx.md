# 見直す項目は、手続き・体制・道具の3つの群に分かれる

| 群 | 項目 | いま | 見直したあと |
| --- | --- | --- | --- |
| 手続き | 見積もりの依頼 | 担当ごとに書式が違う | 書式を1つにする |
| | 承認の段数 | 金額によらず4段 | 100 万円未満は2段 |
| | 発注の記録 | 表計算のファイル | 調達の仕組みに残す |
| 体制 | 窓口 | 部署ごとに7つ | 調達の係に1つ |
| | 相談の担当 | 決まっていない | 係の中で週ごとに当番 |
| 道具 | 取引先の一覧 | 部署ごとに別 | 全社で1つ |
: 見直したあとの形は、2026 年 10 月の調達の会議の案 {groups=first}

:::takeaway
最初に手続きの3項目を揃え、体制と道具はそのあとに移す
:::

- 手続きの2項目だけで、月の件数の8割を占める
- 体制の見直しは窓口への相談を減らすが、件数への効き目は小さい
- 見直しの順は件数の多い群から決める
