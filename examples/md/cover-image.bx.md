# 利用は朝に集まる

:::lead
平日の朝の利用が全体の半分を占め、昼は少ない。朝の混み方をならすことが次の打ち手になる。
:::

::::columns
:::column 分かったこと
- 朝 7〜9時の利用が全体の 48%
- 昼 11〜14時は 12% にとどまる
- 夕方は朝より広い時間に分かれる
- 雨の日は朝の利用がさらに 1.3 倍になる
- 週末は朝の山が無く、昼から夕方に広がる
:::
:::column 次の打ち手
- 朝の便を 2 本足し、待ち時間を短くする
- 昼の割引で、急がない移動を昼へ寄せる
- 雨の日の朝だけ、臨時の便を出す
- 半年後に同じ調べで効き目を確かめる
- 週末は昼の便を厚くし、朝の便を減らす
:::

:::takeaway
朝の混み方をならせば、便を大きく増やさずに待ち時間を減らせる。
:::
