# 公園の清掃の見直し

段落を1つ置き、その下に対を5つ並べる。4つ目の対の打ち手の箇条が長く、
本文の領域の下端を越える(5つ目の対も越える)。

::::pairs 分かったこと | 打ち手
:::subject
落ち葉は 11 月に集中する
:::
:::response
11 月だけ当番を2人にする
:::
:::subject
道具の置き場が遠い
:::
:::response
入口の倉庫に熊手を置く
:::
:::subject
ごみ袋が足りなくなる
:::
:::response
袋を2箱多めに頼む
:::
:::subject
当番の引き継ぎが口頭だけになっている
:::
:::response
- 当番の表を掲示板に貼る
- 終わった場所に印を付ける
- 気づいたことを帳面に書く
- 帳面は月に1度読み合わせる
- 読み合わせの結果を次の当番に渡す
- 渡した記録を倉庫に置く
- 倉庫の鍵の置き場所を決める
:::
:::subject
雨の翌日は作業が進まない
:::
:::response
雨の翌日は清掃を1日ずらす
:::
::::
