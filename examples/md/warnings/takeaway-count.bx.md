# 問い合わせの回り道

:::lead
問い合わせの 4 割は最初の窓口では片づかずに別の窓口へ回される。
:::

- 回された問い合わせは、解決までに平均 2.3 日長くかかる
- 回す先の多くは料金の窓口で、回す理由の半分は権限の不足
- 窓口の権限を広げた架空の試行では、回す割合が半分に減った

:::takeaway
窓口の権限を広げれば、回り道の半分は無くせる。
:::

:::takeaway
料金の窓口の待ち時間も 3 割短くなる。
:::

# 窓口の権限を広げる

- 返金の上限を 1 万円まで窓口で決められるようにする
- 料金の窓口には、窓口で決められない件だけを回す

:::takeaway
権限を広げるのは、来期の最初の 3 か月で試す。
:::
