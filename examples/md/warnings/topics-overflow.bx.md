# 図書館の講座の見直し

段落を1つ置き、その下に塊を4つ並べる。3つ目の塊の箇条が長く、本文の領域の下端を越える
(4つ目の塊も越える)。

::::topics
:::topic 申し込み {label=1}
電話だけだった受付に、窓口と用紙を足す
:::
:::topic 時間帯 {label=2}
- 平日の夜の回を月に2回足す
- 土曜の朝の回は続ける
:::
:::topic 講師 {label=3}
- 地域の書店の店主に、本の選び方の回を頼む
- 元教員の利用者に、調べ方の回を頼む
- 司書が交代で、館の使い方の回を受け持つ
- 回ごとに、次の回の講師を参加者から募る
- 講師の謝礼は、図書券で渡す
- 講師の控え室に、閉架の書庫の一角を使う
- 講師どうしの集まりを、季節ごとに開く
:::
:::topic 振り返り {label=4}
- 回の終わりに、紙の用紙で一言を集める
- 集めた一言は、翌月の便りに載せる
:::
::::
