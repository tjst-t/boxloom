# 来期の候補は多いが、今期は1つに絞る

段落を1つ置き、その下に2つのまとまりを並べる。右のまとまりだけが長く、
本文の領域の下端を越える(左は収まる)。

::::columns
:::column 今期
- 受付の画面を1つにまとめる
:::
:::column 来期の候補
- 外部の窓口との連携を始める
- 古い端末を入れ替える
- 問い合わせの分類を自動にする
- 週次の報告の形を見直す
- 夜間の受付の当番を決め直す
- 帳票の様式をそろえる
- 受付の記録を1年で消す決まりを作る
- 窓口ごとの手順書を1つにまとめる
- 利用者への案内の文を書き直す
- 端末の貸し出しの台帳を電子にする
- 研修の資料を作り直す
- 年に1度の点検の手順を決める
- 問い合わせの多い項目を案内に載せる
- 受付の画面の色の使い方を決める
- 古い帳票の保管の場所を決める
- 担当の交代の手順を書く
:::
::::
