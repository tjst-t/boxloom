# 架空の市場は 3 年で大きく伸びた

::::stat
:::value 1,234,567 {unit=千円}
架空の市場の規模(3 年後)
:::
:::value 3 → 12 {unit=社}
参入した会社の数
:::
:::value 71 {unit=%}
継続して使う人の割合
:::
::::

- 1つ目の数は桁が多く、数と単位を1行に置くとカードの幅を越える(stat-value の警告)
- 数と単位はそれぞれ途中で折らないので、単位だけが次の行に落ちる。値を丸めるか、単位を大きくする
