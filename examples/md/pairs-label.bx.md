# 商店街の空き店舗の要因と打ち手

:::lead
要因の番号ごとに、聞き取りで分かったことと打ち手を並べた
:::

:::::pairs 分かったこと | 打ち手
:::subject {label=1}
空き店舗の多くは 80 平米を超え、小さな店には広すぎる。借りたい店の多くは 30 平米前後を探している
:::
:::response
- 区切って貸せるよう、仕切りの工事に補助を出す
- 区切った区画の図面を組合が用意し、借り手に見せる
- 工事の間の家賃は持ち主と組合で半分ずつ持つ
:::
:::subject {label=5}
持ち主の半分は通りの外に住み、貸す相談の窓口を知らない。空いたまま数年が過ぎた店もある
:::
:::response
- 組合が持ち主に手紙を送り、窓口を知らせる
- 月に1度、貸し手と借り手の相談会を開く
:::
:::subject {label=7}
家賃の相場は周りの通りより2割高く、始めたばかりの店には重い
:::
:::response
- 最初の1年は家賃を下げる取り決めを持ち主と結ぶ
- 下げた分の一部を組合の積み立てから埋める
:::
:::subject {label=9}
店の跡を継ぐ人がいない店主が多く、閉める日を決めかねている
:::
:::response
- 継ぎたい人を探す掲示を組合の窓口に置く
- 道具と常連の客ごと引き継ぐ相談に、組合が立ち会う
:::
:::::

:::source
架空の聞き取り(店主と持ち主 20 人)
:::

# 通りの課題を場面ごとに見る

:::lead
場面ごとに、利用者の声と打ち手を並べた
:::

:::::pairs 聞き取りの声 | 打ち手
:::subject {label="夕方 18 時以降"}
18 時を過ぎると開いている店が少なく、通りが暗い。勤め帰りの客は駅前の店で済ませてしまう
:::
:::response
- 夕方に開ける店に、街灯の電気代の一部を組合が持つ
- 遅くまで開ける店を通りの入口の案内板に載せる
- 夕方だけの品を店ごとに1つ決めて知らせる
:::
:::subject {label=週末の催し}
催しの日だけ人が増え、ふだんの客にはつながらない。催しの客は通りの店を覚えずに帰る
:::
:::response
- 催しの日に、店ごとの次回の割引券を配る
- 催しの地図に、ふだんの営業の日と時刻を書く
:::
:::subject {label=雨の日}
屋根の無い通りなので、雨の日は客が半分に減る
:::
:::response
- 店の前の庇をそろえて、雨でも歩ける道をつくる
- 雨の日だけの割引を組合で決める
:::
:::subject {label=子ども連れ}
ベビーカーで入れる店が少なく、休める場所も無い
:::
:::response
- 段差のある店の入口に、組合が板の坂を貸し出す
- 空き店舗の1つを、休める場所として週末に開く
:::
:::::

:::source
架空の聞き取り(利用者 30 人)
:::
