# 市民農園の区画を割り振る3つの観点

:::lead
抽選の不満を聞き取り、割り振りで見る観点を3つに絞った
:::

:::::topics
:::topic 通いやすさ {label=A}
- 徒歩 15 分より遠い人には、近くの空き区画を先に案内する
- 車で来る人には、駐車場に近い区画を回す
:::
:::topic 続けやすさ {label=B}
初めての人には、相談役の区画の隣を割り振る。去年途中でやめた人の多くが、聞ける相手がいなかったと答えた
:::
::::topic 公平さ {label=C}
抽選の結果と理由を、掲示板と便りの両方で知らせる

:::quote 利用者 D、聞き取りにて
外れた理由が分かれば来年も申し込める
:::
