# 3つの柱が、町の拠点を支える

:::lead
架空の町 Kirinoha の地域拠点は、3つの取り組みと住民の参加の上に立つ
:::

```pillars
roof: だれもが週に一度は立ち寄る、町の居場所になる
pillars:
  - {title: 場をひらく, items: [週末に拠点を開く, 催しを月1回続ける], label: "1"}
  - {title: 担い手を育てる, items: [運営を3人以上で回す, 次の担い手へ渡す], label: "2"}
  - {title: 声を集める, items: [住民30人に話を聞く, 数と声を毎年まとめる], label: "3"}
foundation: 住民の参加と、町の小さな予算
```
