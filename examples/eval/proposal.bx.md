:::lead
置き場の4割が利用の8割を担い、残りの置き場はほとんど使われていない。

| --- | --- | --- | --- |

- 公園と河川敷の置き場は、週末の昼だけに使われる
- 住宅地の置き場は、駅の周りに空きがある日ほど使われない
- 使われない置き場は、住宅地の奥へ移すと効く見込み

# 第2部 次の3年の提案 {type=section}

# 広げ方の案

:::lead
3つの案のうち、地区ごとに段階で広げる案だけが、費用と利用の両方の条件を満たす。
:::

```matrix

  - label: 費用
    detail: 3年の総額
    cells:

      - {status: support, text: 5億円}
      - {status: support, text: 2億円}
  - label: 利用の伸び
    detail: 3年後の月の利用
    cells:
      - {status: support, text: 8万回}
      - {status: support, text: 7万回}

  - label: 運営の負担
    detail: 運ぶ便と点検の人手
    cells:
      - {status: danger, text: 一度に倍}

      - {status: conditional, text: 電動は一部}
```

:::

# 案の長所と短所

:::lead
案Bは広がりが遅いが、毎年の結果を見て次の地区を選び直せる。
:::

:::::compare
::::option 案A 一斉に広げる
:::pros
- 3年目には全域で使える
- 置き場の工事を1回で済ませられる
:::
:::cons
- 初年度に費用の6割がかかる
- 使われない置き場を見直す機会がない
:::
::::
::::option 案B 地区ごとに広げる
:::pros
- 費用を3年に分けられる
- 前の年の利用を見て次の地区を選べる
:::
:::cons
- 最後の地区は3年目まで待つ
- 工事と説明会が毎年ある
- 地区の間で使える時期に差が出る
:::
::::
::::option 案C 試行のまま
:::pros
- 新しい費用がかからない
- 運営の人手を増やさずに済む
:::
:::cons
- 駅から遠い地区では使えないまま
- 国の補助は試行の延長には出ない
- 3年後に車体の入れ替えが要る
:::
::::
:::::

案Aの費用の山は初年度に来るため、来年度の予算の枠に収まらない。案Cは費用が小さいが、試行で利用が少なかった駅から遠い地区の住民には何も変わらない。

:::takeaway
費用を分けて結果で選び直せる **案B** が、いまの予算と人手に合う
:::

# 毎年まわす改善の輪

:::lead
案Bでは、1年ごとに4つの段を回して次の地区と置き場を決める。
:::

::::columns
:::column
```cycle
steps:
  - title: 数える
  - title: 聞く
  - title: 選ぶ
  - title: 置く
```
:::
:::column 段ごとの中身 {role=main}
- **1 数える**:置き場ごとの貸し出しと返却を月ごとにまとめる
- **2 聞く**:新しい地区の住民の会で、置き場の場所の案を聞く
- **3 選ぶ**:利用の見込みと費用から、次の年の地区を2つ選ぶ
- **4 置く**:置き場を作り、使われない置き場を移す
- 輪は毎年4月に始め、3月の議会に次の年の案を出す
:::
::::

# 第3部 進め方 {type=section}

# 3年の進め方

:::lead
毎年の議会で次の地区を決め、3年目の3月に全域の置き場がそろう。
:::

```process
steps:
  - {title: 1年目の準備, detail: 北と東の置き場を決める}
  - {title: 北と東, detail: 電動の車体から入れる, emphasis: true}
  - {title: 西と中央, detail: 駅の置き場を広げる}
  - {title: 南, detail: 住宅地の奥に置く, status: conditional}
  - {title: ふり返り, detail: 全域の利用を数える}
legend:
  conditional: 2年目の利用が見込みに届いたときだけ
```

- どの年も、4月に地区を発表し、7月から置き場の工事に入る
- 3年目の南の地区は、2年目の結果を見て規模を決め直す
- ふり返りの数字は、次の計画を作る時の材料にする

# 今日決めていただきたいこと

:::lead
案Bで進めることと、1年目の北と東の予算1.8億円を決めていただきたい。
:::

1. 広げ方は案B(地区ごとに広げる)とする
2. 1年目の予算1.8億円を来年度の予算案に入れる
3. 北の地区の住民の会を、来年1月に開く
4. 3年目の南の地区は、2年目の結果で決め直す

決めていただければ、1月から北と東の住民の会と置き場の調べに入る。

| 時期 | すること |
| --- | --- |
| 1月 | 北と東の住民の会 |
| 3月 | 置き場の一覧を議会に報告 |
| 7月 | 置き場の工事に入る |

:::takeaway
予算が決まれば、来年7月には北と東で置き場の工事に入れる
:::

:::notes
決めていただくのは1と2。3と4は報告として伝える。
:::
