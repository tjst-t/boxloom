# 要約

:::lead
利用は中央館と駅前館に集まり、4つの地区館は人手の割に使われていない。地区館を2つの型に分けて運営を変えることを提言する。
:::

::::stat
:::value −12 {unit=%}
5年の貸し出しの減り
:::
:::value 47 {unit=%}
地区館にいる職員の割合
:::
:::value 31 {unit=%}
地区館の貸し出しの割合
:::
::::

- **利用**:年の貸し出しは5年で12%減った。減った分の8割は4つの地区館
- **利用者**:平日の昼の利用者の6割が65歳以上で、学生と働く世代は夜と週末に偏る
- **体制**:職員の半分が地区館にいるが、地区館の貸し出しは全体の2割
- **課題**:開館の時間が利用の時間と合わず、蔵書の入れ替えも館ごとにばらばら
- **案**:地区館を「学びの館」と「受け取りの館」に分け、3年で移る
- **費用**:3年で1.2億円の追加。4年目からは年0.4億円の削減
- **進め方**:準備・受け取りの館・学びの館の3つの段で、段の終わりに利用を数えて直す

:::takeaway
地区館を減らすのではなく、**役割を分けて**人手を利用の多い時間に回す
:::

:::

:::
:::topic 夜と週末の利用者 {label=B}
- 学生と働く世代で、平日の18時より後と土日に来る

- 調べに答えた住民の4割は、この1年に一度も館に来ていない
- 来ない理由の上位は「開いている時間に行けない」と「読みたい本がない」
:::
:::::

# 課題と打ち手

:::lead
調べで見えた4つの課題ごとに、打ち手を1つずつ決めた。どれも人を減らさずに、時間と役割を変えるものである。
:::

:::::pairs 課題 | 打ち手
:::subject 開館の時間
地区館は9時から18時で、夜と週末の利用者が来られない
:::
:::response
受け取りの館は11時から20時に移し、平日の夜に開ける
:::
:::subject 選書の重なり
6館がそれぞれ選書し、同じ本を館ごとに買っている
:::
:::response
選書を中央館に集め、地区館の分は館ごとの棚の型で配る
:::
:::subject 受け取りの増加
予約の受け取りは年に1割ずつ増え、貸し出しの窓口が混む
:::
:::response
受け取りの棚を置き、利用者が自分で取れるようにする
:::
:::subject 地区館の役割
4つの地区館が同じ形で、地区ごとの使われ方の違いに合わない
:::
:::response
地区館を「学びの館」と「受け取りの館」の2つの型に分ける
:::
:::subject 古い蔵書
地区館の本の5割が10年より前のもので、新しい本を探す人が中央館へ流れる
:::
:::response
地区館の本を年に1割ずつ入れ替え、新しい本の棚を入口に置く
:::
:::::

# 2つの型の館

:::lead
北館と東館は受け取りの館、西館と南館は学びの館にする。どちらの型も、地区で多い使われ方に時間と人手を合わせる。
:::

:::::compare
::::option 受け取りの館(北館・東館)
:::pros
- 開館を11時から20時にし、平日の夜に開ける
- 受け取りの棚を置き、職員は4人で回す
- 新しい本の棚を入口に置く
:::
:::cons
- 平日の朝は開いていない
- 学習の席は今の半分になる
:::
::::
::::option 学びの館(西館・南館)
:::pros
- 学習の席を倍にし、司書の相談の窓口を置く
- 新聞と雑誌の席を残し、昼の利用者の場を守る
- 地区の学校と催しを月1回開く
:::
:::cons
- 貸し出しの本は今の7割に絞る
- 司書の研修に1年かかる
:::
::::
:::::

| 型 | 館 | 開館の時間 | 職員(人) | 学習の席 |
| --- | --- | --- | --- | --- |
| 受け取りの館 | 北館・東館 | 11時〜20時 | 4 | 今の半分 |
| 学びの館 | 西館・南館 | 9時〜18時 | 6 | 今の倍 |
: 職員は1館あたり。いまは1館7〜8人

- 受け取りの館で浮く6人は、中央館と駅前館の夜と週末に回す
- 学びの館の司書は、中央館の相談の係から2人ずつ移す

:::source
作業部会の案(2026年10月)

# 再編のリスク

:::lead
大きなリスクは3つで、どれも段の終わりに数えて確かめられる。確かめる数と、外れたときの手を先に決めておく。
:::

| リスク | 確かめる数 | 外れたときの手 |
| --- | --- | --- |
| 朝の利用者が離れる | 受け取りの館の朝の問い合わせ | 週2日だけ朝に開ける |
| 夜の利用が伸びない | 18時より後の貸し出し | 開館を19時までに戻す |
| 研修の予算が付かない | 3年目の予算の査定 | 学びの館を1館ずつ移す |
| 受け取りの棚が混む | 棚の空きの割合 | 棚を足すか、受け取りの期限を短くする |
| 選書の係が回らない | 選書から棚に並ぶまでの日数 | 選書の係を1人足す |
| 説明会で反対が多い | 説明会での声の数 | 移る順を入れ替え、反対の多い地区を後にする |
: 確かめるのは各段の終わり

最も起きやすいのは、朝の利用者が受け取りの館から離れることである。北館と東館の朝の利用者は1日平均40人で、その7割が新聞と雑誌を読みに来ている。学びの館に新聞と雑誌の席を残すのは、この利用者の行き先を残すためである。

- どのリスクも、移った館の利用の数で早く分かる
- 外れたときの手は、どれも館を閉じずに済む
- 確かめる数は、毎月の運営の会議で館ごとに見る
- 2つ以上のリスクが同じ段で外れたら、次の段に移る前に作業部会で案を見直す

6つのリスクのうち、説明会での反対だけは段が始まる前に分かるので、1年目の説明会の後に見直す。

# 提言

:::lead
案Bで進めること、1年目の予算0.2億円、選書の係を来年4月に置くことの3つを決めていただきたい。
:::

1. 地区館を「受け取りの館」と「学びの館」の2つの型に分ける(案B)
2. 1年目の予算0.2億円を来年度の予算案に入れる
3. 来年4月に中央館に選書の係を置き、館ごとの棚の型を決める
4. 2年目と3年目の予算は、各段の終わりの利用の数とあわせて諮る
5. 地区の説明会を、1年目のうちに4つの地区で2回ずつ開く

| 時期 | すること | 受け持つ |
| --- | --- | --- |
| 来年4月 | 選書の係を置く | 中央館 |
| 来年6月〜9月 | 地区の説明会を2回ずつ | 作業部会 |
| 来年度末 | 北館と東館の工事の発注 | 事務局 |
| 2年目の4月 | 受け取りの館を開く | 北館・東館 |
: 1年目の主な予定

1から3が決まれば、来年4月に選書の係を置き、2年目の4月に最初の受け取りの館を開ける。

:::takeaway
館の数を変えずに、**時間と役割**を利用者に合わせる
:::

# 調べの方法 {density=dense}

:::lead
この報告の数字は、貸し出しの記録・職員の名簿・利用者の調べ・聞き取り・見積もりの5つから取った。
:::

| 調べ | 対象 | 時期 | 数 | 使った頁 |
| --- | --- | --- | --- | --- |
| 貸し出しの記録 | 6館の貸し出しと予約 | 2021〜2025年度 | 約380万件 | 貸し出しの推移、館ごとの利用 |
| 職員の名簿 | 常勤と非常勤 | 2025年度、2026年4月 | 60人(常勤に直した数) | 館ごとの利用、職員の体制 |
| 利用者の調べ | 6館の来館者 | 2026年6月 | 1,200人 | 利用者の調べ |
| 聞き取り | 利用者 | 2026年7月 | 30人 | 利用者の調べ |
| 地区の説明会 | 4つの地区の住民 | 2026年9月 | 4回、のべ210人 | 再編の案の比べ |
| 見積もり | 棚・工事・研修 | 2026年10月 | 事業者2社 | 費用と効果 |
: 数は延べ数

- 利用者の調べは、各館の入口で配った紙と、ネットの回答をあわせたもの
- 職員の数は、非常勤の勤務時間を常勤に直して数えた
- 費用の見積もりは税込みで、人件費は作業部会の試算による
- 7年目に取り戻す見込みは、4年目からの減りが毎年同じとした場合
- 聞き取りの相手は、利用者の調べの回答者から年代と館が偏らないように選んだ
- 地区の説明会の声は、記録係が書き取ったものを作業部会で分けた
- 貸し出しの数には、電子書籍と館の中だけで読まれた本は入っていない
- 館ごとの数は、予約の受け取りを受け取った館の貸し出しとして数えた
- 説明会の声の数は、同じ人が2回の説明会で話した分も別に数えた
- 利用者の調べの回答のうち、館を書いていないもの(約4%)は館ごとの数から除いた
- 割合は四捨五入しているため、足して100%にならないことがある
