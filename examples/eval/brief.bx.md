# 税の窓口の遅れ

:::lead
本人確認の画面でやめる人が多いため、画面を作り直している。12月に作り直しを終え、年度末までに遅れを取り戻す。
:::

- 本人確認の画面に進んだ人の45%が、そこで申請をやめている
- やめた人に聞くと、写真の撮り直しを何度も求められたという答えが多かった
- 作り直しでは、写真の代わりに市の窓口で受けた確認を使えるようにする
- 作り直しの2か月は、税の証明の受け付けの開始を12月に延ばして吸収する
- 年度末までの残りの作業は受け付けの試験だけで、人手は今のままで足りる
- 遅れが年度末を越えそうなときは、1月の会議で受け付けを窓口と並べて始める案を諮る

:::takeaway
本人確認の作り直しを **12月** に終えれば、年度末の目標に間に合う
:::

:::source
税の窓口の利用者への聞き取り(2026年9月、28人)
:::

# 下期にすること

:::lead
下期は、電子で受けられる手続きを12から20に増やし、窓口の人手を相談に回す。
:::

1. 電子で受けられる手続きを8つ増やす(保育の申し込み・税の証明など)
2. 住民票の写しの支払いを電子にする
3. 窓口の受け付けの係から2人を、電子の申請の相談の係に移す
4. 電子の申請の使い方の講座を、地区の会館で月に2回開く
5. 年度末に、電子の割合と待ち時間を数えて次の年度の目標を決める

| 指標 | 上期 | 年度末の目標 |
| --- | --- | --- |
| 電子の申請の割合 | 38% | 45% |
| 電子で受けられる手続き | 12 | 20 |
| 窓口の待ち時間(前の年と比べて) | −21% | −30% |
: 年度末の目標は事業の計画(2026年4月)のとおり
